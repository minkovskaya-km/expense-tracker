# Бизнес-трекер (Kivy)

Практическое задание к лекции 6: трекер доходов и расходов.

Реализовано по пунктам задания:
1. Графики Matplotlib (Kivy Garden) — кнопка «Аналитика»: расходы и доходы по категориям, итог.
2. Синхронизация с облаком по REST API (Firebase Realtime Database) — кнопка «Синхр.», адрес в «Настройках».
3. Категории доходов и расходов, баланс на главном экране.

## Запуск
    pip install -r requirements.txt
    python main.py          # обычный .py файл, не Jupyter/Colab

Быстрый показ: Настройки → «Добавить демо-данные».

## Облако
В Firebase создайте Realtime Database, в правилах разрешите чтение/запись, адрес вида
`https://проект-default-rtdb.firebaseio.com` вставьте в «Настройках». Операции хранятся в `/transactions.json`.
Побеждает запись с более поздним временем изменения; удаление тоже синхронизируется.
